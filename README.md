# Portfolio d'Élégance Digitale

Role: Act as a Senior Web Designer and Frontend Developer. Task: Create a high-end, dynamic personal portfolio website for an E-Business student. Style: Dark Mode (pure black/dark anthracite background) with Gold accents. Modern, sleek, "Glassmorphism" effects, and mobile-first responsive design.

CRITICAL INSTRUCTION: All visible text content must be in FRENCH.

Structure & Content:

Hero Section: Display my name and surname with a professional profile picture.

Tagline (in French): "Marketing digital • Intelligence artificielle • E-commerce • Développement web • UX/UI design • Création de contenu • Analyse digitale"

CTA Button: "Me contacter" or "Voir mon CV".

About Section (in French): A short bio about being a HEPL student passionate about innovation, AI, and e-commerce. Highlight values: "esprit d'équipe, générosité et curiosité technologique".

Projects Section (in French - use modern cards):

Projet Web Scuderia Ferrari : Création d'un site sur mesure (WordPress, VS Code, Photoshop) sur l'écurie et les pilotes.

Stratégie Digitale PME : Analyse physique et digitale, calendrier éditorial et création de contenu pour une PME belge.

Audit UX Neuhaus : Analyse des bonnes pratiques UX/UI du site Neuhaus.

E-Commerce de Luxe : Plateforme de location de voitures électriques haut de gamme (en cours).

Startup Studio - Bougies Belges : Entreprise fictive de bougies artisanales, prospection et stratégie de vente.

App Développement : Application de gestion de budget type 'Tricount'.

Skills (Animated Marquee): Create a continuous scrolling logo bar with: WordPress, VS Code, GitHub, Odoo, Photoshop, Lovable, Figma, ChatGPT, Gemini, Microsoft 365, Canva.

Interests Section (in French): Use icons for "F1, Football (Standard de Liège), Cyclisme, Veille IA & Commerce".

Footer: Contact icons for LinkedIn and Email.

Technical details: Use Lucide-react icons, smooth scrolling, and high-quality typography (sans-serif).
